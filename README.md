# Online Medical Store Web Application

A full-stack e-commerce web application developed to simulate an online pharmacy platform where users can browse medicines, add products to cart, and place orders.

## Technologies Used

* Java
* Spring Boot
* Angular
* MySQL
* HTML, CSS, JavaScript
* REST API
* Postman (API Testing)

## Features

* User registration and login authentication
* View available medicines/products
* Add to cart and remove from cart
* Place order functionality
* Admin dashboard to manage products
* Order summary generation

## System Architecture

The frontend (Angular) communicates with the backend (Spring Boot) using REST APIs.
The backend processes business logic and interacts with MySQL database for storing users, products, and order details.

## How It Works

1. User logs in to the system
2. Selects medicines from product list
3. Adds items to shopping cart
4. Places order
5. Order details stored in database
